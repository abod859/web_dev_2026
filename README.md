# Abdullah Alhaideri's Personal Website

A responsive personal website created as part of an Information and Communication Technology (ICT) course. The project demonstrates semantic HTML5, accessible page structure, responsive CSS, and basic structured data.

## Live Demo

[View the website on GitHub Pages](https://alhaideri.github.io/web_dev_2026/)

## Pages

- **Home** - introduction and website overview
- **About Me** - background, education, interests, and future goals
- **Hobbies** - favorite activities and Arabic calligraphy

## Features

- Semantic HTML5 elements
- Responsive layout for desktop and mobile screens
- Accessible navigation and image alternative text
- CSS Grid and box-model examples
- Responsive images using the `<picture>` element
- Schema.org structured data in JSON-LD format

## Technologies

- HTML5
- CSS3
- GitHub Pages

## Run Locally

No installation or build step is required. Clone or download the project, then open `index.html` in a browser.
